NetO Dynamic Library

0.1.0-theoretical · Roblox network-ownership / physics observation runtime

NetO is a read-only research library for assembling client-visible physics signals into one consistent diagnostic model. It does not implement RakNet and does not claim to seize server authority.

Core model

BasePart
   ↓
AssemblyRootPart
   ↓
┌─────────────────────────────┐
│ NetworkOwnerV3             │ optional hidden read
│ NetworkOwnershipRule       │ optional hidden read
│ NetworkIsSleeping          │ optional hidden read
│ ReceiveAge                 │ read-only observation
│ AssemblyLinearVelocity     │ public physics state
│ AssemblyAngularVelocity    │ public physics state
└─────────────────────────────┘
   ↓
NetO Snapshot → Tracker → Timeline / Profiler

Requirements

Baseline
Roblox Luau + BasePart assembly APIs
Optional
gethiddenproperty for full hidden-state reads
Not required
sethiddenproperty, setthreadidentity, replicatesignal

Quick start

local NetO = loadstring(readfile("NetO.lua"))()

local Players = game:GetService("Players")
local character = Players.LocalPlayer.Character
local root = character:FindFirstChild("HumanoidRootPart")

print(NetO.FormatSnapshot(NetO.Probe(root)))

Security metadata

MemberCurrent relevant metadata
NetworkOwnerV3Hidden, NotScriptable
NetworkIsSleepingHidden, NotScriptable
NetworkOwnershipRuleHidden, NotScriptable
NetworkOwnerChangedHidden, LocalUserSecurity
ReceiveAgeHidden, ReadOnly, NotReplicated
ReplicationPVHidden, NotScriptable, RobloxSecurity

NetO does not prescribe a numeric executor identity. It tests the actual capability it needs. Thread identity is diagnostic metadata only.
